# rings.py — 画像 → 等高線リング・ハーフトーン STL 変換器

Convert an image into a concentric-ring halftone and export it as an STL
for 3D printing — e.g. printing an image in PLA onto fabric or paper.

画像を「等高線モアレ」的なリングの集まりに変換し、3Dプリント用の STL を
出力する単独スクリプト。布や紙の上に PLA で絵を刷る用途を想定している。

## 仕組み

- 階調レベルごとに「そのレベルより暗い領域」のマスクを取り、距離変換で
  一定ピッチのリングを内側に描く。暗い場所ほど多くのレベルのマスクに
  含まれるためリングが重なって密度が上がり、白い場所はどのマスクにも
  入らないので本当に白いまま残る。
- ベタ塗りは一切なく、線幅は常に一定。だから刷ったものが板状に硬く
  ならず、スライサーにも「線は線」として解釈される。
- メッシュ化は連結成分ごとにポリゴン化し、画素中心トレースによる
  半画素の痩せを +0.5px 補正で戻す。面積が合わない成分は矩形分解に
  フォールバックするので、ラスタのインク量に対して忠実な STL になる。

## インストール

```sh
pip install -r requirements.txt
```

## 使い方

```sh
python rings.py input.jpg
```

出力（入力画像と同じ場所、または `--out-dir` で指定した先）:

| ファイル | 内容 |
|---|---|
| `<name>-rings.png` | フル解像度の白黒ラスタ |
| `<name>-rings-preview.png` | 縮小プレビュー |
| `<name>-rings.stl` | 印刷用メッシュ（デフォルト 200mm 幅 × 0.8mm 厚） |

## オプション

| オプション | デフォルト | 説明 |
|---|---|---|
| `--width-mm` | 200 | 印刷幅 (mm) |
| `--thickness` | 0.8 | メッシュの厚み (mm) |
| `--levels` | 70,105,140,170,200,228 | 階調しきい値（暗い側、カンマ区切り） |
| `--pitch` | 11 | リングのピッチ (px) |
| `--line-width` | 3 | 線幅 (px) |
| `--preview-width` | 820 | プレビューの幅 (px) |

ピッチと線幅は入力画像の解像度基準。200mm 幅で刷る場合、1280px 幅の
画像ならピッチ 11px ≒ 1.7mm、線幅 3px ≒ 0.47mm（0.4mm ノズルの
1本線相当）になる。

## 印刷のメモ

- 紙や布に刷るときは、素材をベッドに平らに固定してから素材の厚み分を
  考慮して Z オフセットを取る。
- 急冷すると反るので、ベッドの上でゆっくり冷ますとよい。
